Inclusions  
 
Metal Framing & Drywall: 
1. Frame new exterior soffits as shown 
2. Frame new interior walls, ceilings and soffits as shown 
3. Frame metal stud jambs and headers as shown 
4. Furnish and install 6” metal backing for grab bars, toilet accessories 
5. Install access doors (supplied by others) 
6. Acoustical sealant at base of wall  
7. Furnish and install 5/8” Type X drywall throughout 
8. Furnish and install 5/8”  Dens Shield at walls scheduled to receive FRP  
9. Furnish and install 5/8” Dens Glass sheathing at exterior soffits  
10. Level 3 finish throughout, fire tape above ceilings  
11. All exposed drywall to receive splatter texture 
 
Acoustical Ceilings: 
1. Furnish and install Armstrong 2712 Dune 2 x 4 tile with standard 15/16” white grid  
2. Furnish and install Armstrong 870 Cleanroom VL 2 x 4 tile with standard 15/16” white grid  
3. Furnish and install two (2) wires per light fixture within ACT ceiling system 
4. Based on being able to attach directly to deck above 
 
FRP Panels: 
1. Furnish and install white textured FRP panels with matching vinyl trims in Kitchen 8’ AFF 
2. Furnish and install drak grey textured FRP panels with matching vinyl trims in restrooms 8’ AFF 
 
Painting & Finishes: 
1. Utilization of Sherwin Williams paint products 
2. All painting to be done before acoustical ceilings, millwork, wood doors and fixtures are installed 
3. Paint exposed drywall walls and ceilings (1 coat primer followed by finish coats)  
4. Paint of hollow metal doors and frames 
5. Paint of exposed deck (1 color – All items are to be installed within the open ceiling prior to painting 
of exposed structure) 
6. Anti-graffiti coating at exterior CMU of concession/restroom building 
 
 
 
 
Qualifications

3. All equipment, lifts and hoisting necessary to complete our scopes of work are included 
4. Delegated design engineering for light gauge framing is not included 
5. Layout is included for our scopes of work only
